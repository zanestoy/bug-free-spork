LIGHTS OUT - WEB GAME
=====================

Play locally: Open index.html in any modern browser. The game works without
internet or installations.

Play online for free with GitHub Pages:
1. Create a public GitHub repository (for example, lights-out).
2. Upload index.html to the repository root and commit it.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose your main branch and /(root), then Save.
6. After publishing, open https://YOUR_USERNAME.github.io/lights-out/

Rules: Clicking a light toggles it and adjacent lights above/below/left/right.
Turn off all the lights to win. Every generated puzzle is solvable.

Game includes three difficulty levels, a minimum-solution hint, undo,
restart, a timer, move tracking, personal bests (browser-local), and
shareable puzzle URLs.

Everything is contained in index.html. There are no dependencies.
